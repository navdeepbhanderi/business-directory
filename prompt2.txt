You are a senior React engineer extending an existing React 19 + TypeScript + Tailwind v4 + shadcn/ui demo for a Bahrain local business directory and review platform. Implement detailed, production-like UIs with mocked data and a fake API only. No real backend, SSO, OTP, maps, or payments. Ensure i18n (EN/AR) and RTL, accessibility, and responsive behavior.[1][2][3]
Scope
Implement the following next modules with precise UI, data shapes, and flows:
    • Advanced Search & Filters
    • Business Profile v2 (media, services, offers, reviews)
    • Lists & Bookmarks v2
    • Owner Claim Wizard v2 and Business Registration v2
    • Owner Dashboard v1
    • Admin Console v1 (Users, Listings, Reviews, Pricing, Premium)
    • Pricing & Checkout Mock v1
    • Notifications Settings v1
    • i18n/RTL hardening and Accessibility QA kit
    • Demo Data & Mock API contracts v2[2][3][1]
Tech constraints
    • Stack: Vite + React 19 + TS, Tailwind v4, shadcn/ui (new-york), Radix, lucide-react.[1]
    • Routing: React Router with route layouts, query param preservation, 404.[1]
    • State: Zustand slices (auth, lists, ui) minimal and predictable.[1]
    • Data: JSON seeds in /src/data; mock API in /src/lib/api.ts with latency and small error rate.[1]
    • i18n: /src/i18n en.ts and ar.ts with dir toggle.[1]
    • A11y: labels, aria-*, keyboard nav, focus traps.[1]
Module 1 — Advanced Search & Filters
Goal: Make “/search” feel real with URL-driven filters, sticky desktop filters, mobile bottom sheet, list/map toggle, and infinite scroll.[2][1]
    • UI
        ◦ Header: Search input, category select, location combobox, Submit button.[2]
        ◦ Filters panel: switches and sliders for openNow, minRating, distanceKm; multi-select category; price range mock.[2]
        ◦ Sort dropdown: best_rated, most_reviewed, nearest, newest.[2]
        ◦ Active filter chips with “Clear all”.[1]
        ◦ Results grid (Card) and Map panel toggle; Map uses placeholder div pins synced with selection.[1]
        ◦ Skeletons for initial and paginated loads.[1]
    • Data contract
        ◦ searchBusinesses(params): { q?: string; categoryIds?: string[]; location?: {lat:number; lng:number} | string; openNow?: boolean; minRating?: number; distanceKm?: number; sort?: ‘best_rated’|‘most_reviewed’|‘nearest’|‘newest’; page?: number; pageSize?: number } → { items: Business[], total: number, page: number, pageSize: number } [1]
    • URL sync
        ◦ Read/write filters to query string; shallow updates; back/forward friendly.[1]
    • Acceptance
        ◦ Filters reflect in URL; reload restores state; paging increments; map/list persists; a11y: all controls labeled; RTL flips paddings and chevrons.[2][1]
